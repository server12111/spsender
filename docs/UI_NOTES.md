# Интерфейс 2.0.2

- Главное меню, списки, выбор аккаунтов, фильтры и периоды — по две кнопки в ряд. Длинные разрешения и подтверждения остаются отдельно.
- Переходы между текстовыми экранами обновляют текущее сообщение. Медиа открывается отдельно; если старое сообщение нельзя изменить, отправляется новый экран.
- Пары по-прежнему формируются автоматически внутри рассылки при добавлении или назначении аккаунтов. Ручное связывание сохранено в «Пары → Настройка пар» как дополнительная операция.
- В карточке аккаунта виден партнёр и есть переход к паре. В карточке пары доступны оба аккаунта.
- Основные настройки и параметры очереди разделены. Статистика сначала показывает краткую сводку; полные показатели доступны через «Подробности».
- Никаких изменений очереди отправок, смен, подготовки аккаунтов или правил разрешения публикаций.

Проверка: `python -X utf8 -m pytest tests/test_bot.py tests/test_hardening.py` (65 проверок, без внешней сети), Ruff и компиляция. Добавление второго аккаунта, автоматическая пара и навигация проверяются через имитацию Bot API.
